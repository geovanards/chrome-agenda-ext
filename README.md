# 🚀 chrome-ext-bootcampII-2

Uma extensão para Google Chrome desenvolvida durante o **Bootcamp II**, com foco em boas práticas de **containerização (Docker Compose)** e **Integração Contínua (CI) com GitHub Actions**.

---

## 🧾 Sobre

Projeto exemplo de extensão Chrome com pipeline de desenvolvimento moderno: ambiente containerizado para desenvolvimento e pipeline CI para rodar testes e builds automaticamente.

---

## 🧩 Tecnologias

- Node.js (versão recomendada: 18+ / 20+)
- npm / pnpm / yarn (conforme `package.json`)
- Docker + Docker Compose
- GitHub Actions (CI)
- HTML / CSS / JS (ou TypeScript) para a extensão
